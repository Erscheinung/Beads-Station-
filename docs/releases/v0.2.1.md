# Beads Station v0.2.1 (prerelease)

Plan, findings and decisions: [`docs/roadmap-0.2/HOLISTIC-UPGRADE.md`](../roadmap-0.2/HOLISTIC-UPGRADE.md).

## What is new

- **Restored agent panes are conversations.** After a restart, a pane that ran Claude or Codex shows that conversation (searchable, scrollable) with a message box. Enter reopens the CLI on exactly that conversation; typed text is sent as the first message. Nothing starts until you act. The saved screen is one click away. Claude's session id also comes from `~/.claude/sessions/<pid>.json`, so a hand-typed or aliased `claude` is found.
- **Optional automatic continue** (Settings → Sessions, off by default): reopens a restored pane's CLI when the pane is shown and its exact conversation is known. Cost of reopening is unmeasured; no claim is made.
- **One top bar** for Terminal and Designer, with Claude, Codex and Gemini launchers using the commands in Settings → Sessions (start and resume honour them), plus an Editor command setting.
- **Shortcuts:** Cmd+Shift+D flips Terminal and Designer, Cmd+Y History, Cmd+/ cheat sheet, Cmd+Shift+H/J/K/L pane focus. The browser pane moved to Cmd+Shift+B (a saved old binding migrates). The palette finds workspaces, tabs and recent conversations.
- **Cmd+click opens files in the editor:** `path`, `path:line:col`, `~/path`; the Explorer, History file chips and Session changed files too. A vi-like editor already in the foreground is reused with `:edit`.
- **Designer:** purpose line per view, History conversation look, Pinned (was Shelf) with drops and Obsidian notes, a live Agents view with subagents and a session timeline, Requests board with focus lens, bounded columns and epic groups, binary changes shown in Session.
- **Fixes:** paste with no focused field goes to the active pane; the browser pane says "Nothing is answering at ..." for a dead address.

## Works, and does not (yet)

- Works (automated evidence only): all of the above in Chromium with mock IPC, Rust unit tests against real session-file formats on the build machine.
- Not confirmed by hand in the packaged app: everything native (real PTY, WKWebView focus and paste, the terminal host, `~/.claude/sessions` beyond Claude Code 2.1.x, both CLIs' resume with a typed first message, reusing a running nvim). The paste fix addresses a cause found by reading, not a reproduced bug. A plain-http page in the browser pane may be blocked in the packaged app.
- Screenshots in `docs/images/releases/v0.2.1/` come from the Chromium test harness with a made-up sample project (Requests, Session, History, Pinned, Agents, Timeline, bead map, terminal, About). They are not of the packaged app.
- Phone view, session tree and automations are future work.

## Install

Download the DMG from the release page, open it and drag Beads Station to Applications. The app is ad-hoc signed, not notarized: on first launch use right-click then Open. Check the download with `shasum -a 256 <file>`.
