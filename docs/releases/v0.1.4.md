# Beads Station v0.1.4 — daily-driver fixes

Apple Silicon macOS preview. This compatible fix release does not complete the Designer or durable runtime roadmap.

## Install or upgrade

Download `Beads.Station_0.1.4_aarch64.dmg` and its `.sha256` from this release.
Run `shasum -a 256 -c Beads.Station_0.1.4_aarch64.dmg.sha256`, quit the old app after saving work, open the DMG, and drag Beads Station to Applications. Saved layout is not a surviving process.
The app is ad-hoc signed, not Developer ID signed or notarized. If macOS blocks launch, use the normal right-click Open or Privacy & Security approval flow.

## Changes

- About Settings reads the app version.
- Confirm closing a terminal pane, workspace, or app; “Don’t ask again” is reversible in Settings → Sessions → Confirm destructive actions.
- Versioned native storage migrates settings, keybindings, and semantic recipes. macOS path: `~/Library/Application Support/ai.beads-station.desktop/user-preferences.json`. Credentials and raw provider/session content are excluded.
- Accepting the Finder folder chooser immediately loads the selected workspace.
- Directional tile switching transfers keyboard focus to the retained terminal.
- Claude/Codex chat frames use sequence identities to prevent duplicates when live delivery overlaps saved output replay.

## Known limits and direction

- Terminal streaming scroll jumps and workspace/tab scroll retention remain under investigation; chat deduplication does not establish a fix for terminal scrolling.
- Real upgrade migration, keyboard/IME behavior, and complete real-provider Designer acceptance remain native follow-up gates. Storage errors currently fall back to browser preferences; disk persistence is not guaranteed if the native store fails.
- Automatic updates remain future work, including two-remote release endpoint selection and safe restart. Only origin is currently configured in this checkout.
- Designer local artifact review is available; durable orchestration, harness profiles, external intake, complete provider journeys, signing/notarization, and performance acceptance remain open.
- Apple Silicon macOS only; Intel, Windows, and Linux packages are not supplied. No provider/authentication work call was made for this release.

## Hands-on checklist

- Check Settings → About for 0.1.4.
- Close a disposable pane; cancel, confirm, and verify the reversible preference.
- Reopen the app and check custom bindings/recipes.
- Choose a folder in Finder and verify immediate workspace loading.
- Switch terminal tiles and type into each; scroll up while local output streams, then switch tabs/workspaces and report any jumps.
- Inspect local Designer artifact revisions; real-provider workflows require separate explicit intent.
