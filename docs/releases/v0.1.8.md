# Beads Station v0.1.8 (rolling, not released)

New bugs and features since v0.1.7. Version files stay at 0.1.7 until this is cut.

- **Native menu bar.** File, View, Window and Help gain the app's own actions, and there is a new Agents menu. Help has Release Notes and Report a Bug or Request a Feature. Items run the same commands as the palette and have no fixed shortcuts, so rebinding keeps working.
- **Right-click a folder → Open Folder in Beads Station.** macOS: a Finder service, under Quick Actions or Services. It needs a selected folder; the empty background of a Finder window would need a Finder Sync extension, which needs a Developer ID. Windows (folder and folder background) and Linux (Open With) are written but have never been built or run.
- **Clone a repository.** The address field fills the row.

## Checked

- The Finder service was called through `NSPerformService` on a renamed copy of the built app, both with the app closed (it launches) and running. The folder reached the workspace store each time.
- Native menu commands match the frontend's command list (Rust test). The menus themselves have not been clicked.
- Not checked: the right-click menu itself in Finder, Windows, Linux.

## After installing

If the item is missing from Finder, run `/System/Library/CoreServices/pbs -update`, or turn it on under System Settings → Keyboard → Keyboard Shortcuts → Services.
