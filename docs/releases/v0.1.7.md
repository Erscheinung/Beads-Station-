# Beads Station v0.1.7

Apple Silicon macOS preview. This release stops the crash that took the whole app down, adds back-pressure so a noisy program cannot fill memory, rebuilds the Designer's Requests and bead map, and fixes the terminal, keyboard and browser problems found while using 0.1.6.

The browser tests run against a mock backend. Nothing here has been run in the packaged app yet; see the checklist.

## Install or upgrade

Download `Beads.Station_0.1.7_aarch64.dmg` and its `.sha256` from this release.
Run `shasum -a 256 -c Beads.Station_0.1.7_aarch64.dmg.sha256`, quit the old app after saving work, open the DMG, and drag Beads Station to Applications. Or use Settings → About → Install from 0.1.6.
The app is ad-hoc signed, not Developer ID signed or notarized. If macOS blocks launch, right-click the app and choose Open, or allow it in Privacy & Security.

## Changes

### Crash resistance and performance

- **The crash.** Three crash reports from 0.1.6 show the same abort on the main thread: the windowing library's `sendEvent:` handler is an `extern "C"` function, so any Rust panic or Objective-C exception reaching it kills the process, and every in-process shell with it. The handler is now replaced by one that catches both, drops that one event, and carries on.
- **Finding the trigger.** Those reports do not say what raised the error, because a Finder-launched app has no stderr. Panics and recovered events now go to `~/Library/Logs/ai.beads-station.desktop/crash.log`, shown in Settings → About.
- **Godot.** The one Godot crash report on this machine is a separate abort inside Godot, while it registered with the window server under `codex`, about 50 minutes after the last Beads Station crash. Whether Godot windows triggered the app's own aborts is not proven by the reports; the guard covers either case.
- **Flow control.** Terminal output now has back-pressure. Once 2 MB of a pane's output is waiting for xterm, the reader pauses and the program blocks, as it would on a slow terminal. No output is dropped. This applies to normal panes; kept terminals (the background host) are not covered yet.
- **The page survives.** If macOS kills the web view (memory pressure), the app reloads it instead of showing a blank window. Running shells in normal panes do not reattach after that; their panes come back as saved screens.
- **One pane's error stays in that pane.** A drawing failure shows a Draw it again button rather than blanking the app.
- **Less background work.** Saved screens are written every 5 seconds rather than 2, and only when the screen changed. The Designer loads only when opened.

### Designer

- **Requests is a board:** Ready to start, In progress, Waiting on something, Done. Search, priority, what a card waits for, and its epic are on the card.
- **The bead map is readable.** It used to draw parent-child links as if they were blockers, and showed every closed bead. Now each epic is a lane with a progress bar, arrows mean "must finish first", and finished beads are hidden until you ask.
- **Select a bead** and its waiting chain turns red and what it holds up turns green; everything else dims.
- **Click to inspect, double-click to open**, for any bead in any state. The inspector and the request page both link to the parent, blockers, dependants, children and related beads.
- **Search and state filters** on the map.
- The request page loads the bead's acceptance criteria and notes, and includes them in the agent's prompt.

### Keyboard

- **Moving between panes moves the cursor.** The keyboard could highlight another pane while typing stayed in the old one: the other pane's input counted as "the user is typing somewhere else".
- **New default shortcuts, without Option.** Option changes the character a key reports on macOS, so several old defaults could never fire.

| Action | Shortcut |
| --- | --- |
| Focus pane | `Cmd+Shift+Arrow` |
| Resize split | `Ctrl+Shift+Arrow` |
| Workspace 1–9 | `Cmd+1…9` |
| Previous / next workspace | `Cmd+[` / `Cmd+]` |
| Terminal tab 1–9 | `Ctrl+Shift+1…9` (`Cmd+Shift+3/4/5` are macOS screenshots) |
| Previous / next terminal tab | `Cmd+Shift+[` / `Cmd+Shift+]` |
| Close workspace | `Cmd+Shift+W` |

Saved copies of the old defaults move to the new ones. A shortcut you chose yourself is kept.

### Terminals and panes

- **Agents start in a terminal pane.** Start Claude chat now runs the real CLI in a new pane. Settings → Sessions has the command for each CLI (`claude --dangerously-skip-permissions`, `codex --yolo`) and can bring back the old chat panel. Nothing starts without a click.
- **Chats can be closed:** a close button on the chat panel and on agent panes.
- **Drops land where you drop.** macOS reports drop positions in points but the app halved them, so everything landed in the left pane.
- **Dragging tabs works.** Workspace and terminal tabs reorder by dragging; the system's drag events never reach the page in this web view.
- **Join tabs** puts tabs back side by side after Unsplit to tabs.
- **Terminal limit raised** from 16 to 128 (`BS_MAX_TERMINALS`).
- **Clone a repository** from Open workspace.

### Browser pane

- **Dragging a split over a page ends when you let go**, and no longer sticks to the cursor. The same fix covers every resize handle.
- **A close button** on the pane.
- **Cmd+click** a terminal link opens it in the browser pane.
- **Sites that refuse to be framed say so** instead of showing a blank page, and offer a window or your default browser. Plain `http://localhost` pages are explicitly allowed.

### Other

- Settings → About and What's New link to the release notes.

## What works

- Crash guard against real panics and real NSExceptions in unit tests.
- Flow control logic in unit tests; every browser test passes against the mock backend.

## What does not work yet

- The crash guard and flow control have not been run in the packaged app.
- The original trigger of the 0.1.6 crash is unknown until `crash.log` catches one.
- Flow control does not cover kept terminals.
- The browser pane is still a frame, so sign-in pages need the Window button (`Code-vjy`).
- Memory is not yet measured against cmux (`Code-2mx`).
- "Copy/paste is wonky" still needs a concrete example.
- The Opus conductor has still not made a real run.

## Hands-on checklist

1. Install over 0.1.6. About shows 0.1.7, What's New appears once, settings are kept.
2. `Cmd+Shift+Left/Right` between two panes: typing follows.
3. Run a flood in a pane (`yes | head -c 2000000000`). The app stays responsive and memory stays flat. Ctrl-C stops it promptly.
4. Open a Godot project from Claude Code or Codex. The app stays up. Check Settings → About for anything recovered.
5. Drop a Finder file on the right-hand pane.
6. Drag a workspace tab and a terminal tab.
7. Open a browser pane on `http://localhost`, drag the split across it, release over the page.
8. Open example sites: a refused one shows the message.
9. Start Claude chat with a custom command in Settings → Sessions.
10. Designer → Requests, then Bead map: click, double-click, search, Done toggle.
11. Unsplit to tabs, then Join tabs.
12. Close a workspace with `Cmd+Shift+W`.
13. Clone a small repository from Open workspace.
