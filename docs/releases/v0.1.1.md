# Beads Station v0.1.1 — early preview

Beads Station v0.1.1 is an Apple Silicon macOS preview. This compatible preview update improves workspace and recipe capabilities while the application remains an incomplete `0.x` preview.

## Install or upgrade

1. Download `Beads Station_0.1.1_aarch64.dmg` and its `.sha256` file.
2. Verify the archive with `shasum -a 256 -c 'Beads Station_0.1.1_aarch64.dmg.sha256'`.
3. Open the DMG and drag **Beads Station** to **Applications**, replacing an older copy if prompted.
4. The package is ad-hoc signed and not notarized. If macOS blocks it, right-click the app, choose **Open**, or allow it once in **System Settings → Privacy & Security**.

## What is new

- A lightweight workspace finder and a native Finder-backed Browse action.
- Honest close/quit confirmation and passive layout restoration; local PTYs and provider processes are still not durable across app restart.
- Explicit Beads initialization with existing-store refusal, argument validation, classified failures, and post-success refresh.
- Persisted workspace and terminal-tab ordering, direct/next/previous selection, keyboard reordering, and accessible announcements.
- Versioned semantic interaction recipes with explicit recording, typed inputs, import/export/migration, bounded undo, authorization, timeout and recursion limits, plus a review fixture.

## Known limits

- The Designer remains a prototype; no dependable request → provider run → artifact preview → revision → approval workflow is claimed.
- CLI authentication and paid provider flows were not exercised.
- The package is Apple Silicon-only; Intel macOS, Windows, Linux, auto-update, signing, and notarization are not included.
- Packaged WKWebView/Finder Browse, real terminal/Neovim/IME, reduced-motion, Beads missing-binary/permission, and recipe lifecycle checks have not yet been performed.

## Hands-on checks requested

- Open and close a workspace with both the finder and native Browse action.
- Open multiple workspace and terminal tabs, reorder them with pointer and keyboard controls, then restart and confirm ordering.
- Initialize Beads in a disposable repository; confirm an existing store is refused.
- Record, edit, export, import, and replay the review recipe; ensure no raw terminal input or clipboard content is recorded.
- Type, paste Unicode, use IME, and run a normal Neovim/LazyVim session in the packaged app.
