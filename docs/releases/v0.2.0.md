# Beads Station v0.2.0

The Designer stops competing with the terminal and starts feeding off it. Plan and reasoning: [`docs/DESIGNER-DESK.md`](../DESIGNER-DESK.md). This release also carries the 0.1.8 work (native menus, Finder action), so there is no separate 0.1.8 release.

## Designer Desk

- **History.** Every Claude Code and Codex session that ran in a folder, read as a formatted conversation: markdown, collapsed tool calls with results, files changed per turn, search, jump to top or latest. It reads the CLIs' own session files, so it uses no tokens, works after a restart, and shows a session a terminal is still running.
- **Resume in Session.** One explicit click starts the CLI on exactly the session you were reading. Disabled while a session is already running.
- **Ticket ↔ session links.** A ticket lists the sessions whose opening prompt names it; click one to read it in History.
- **Shelf.** Paste text, a file path or a markdown-note path (an Obsidian note works), pin an agent's answer from History, then type it into the Designer session or the active terminal pane. Works with any agent; never presses Enter.
- **Session usage.** Each session's size (new input, output, cached) for both Claude Code and Codex, in History and as a small chip on a live agent pane in the Terminal view. Read from the session file; no network.
- **Quieter History.** Your prompts are anchors, the agent reads as plain text, and runs of tool calls fold into one line. Codex commands show as the command, not as the script around it.
- **Usage meter.** Codex 5-hour and weekly windows against an even burn (from the rate limits Codex writes into its own files; a snapshot, not live), and Claude output tokens per day for a week. Local only, no network or credentials. Large sessions that were only partly read are flagged.

## Terminal

- **Restore split** undoes Unsplit (button in the pane toolbar, and a command). Terminals are not restarted.
- **Cmd+click** a web link opens the browser in a new tab; Cmd+click a markdown path opens its folder in a file tab. Only http and https links open.
- **After a restart,** a pane that ran Claude or Codex shows that conversation read-only and scrollable (when its exact session is known); Resume stays an explicit button. The saved screen no longer hides its last line or runs off the edge, and the resume note is one short sentence with the command on hover.
- Paths in the pane header show `~`; workspace tab names have a hover title and more room.
- Web pages on localhost that forbid framing now say so and offer Window, instead of showing blank.
- Larger toolbar buttons.

## From 0.1.8

- Native File, View, Window and Help menus plus an Agents menu, running the same commands as the palette.
- Finder right-click action: Open Folder in Beads Station (macOS). Windows and Linux hooks are written but have never been built.
- The clone-a-repository field fills its row.

## Fixed on the way

- A resume requested while the Session view was mounting could be dropped. A queued start now counts as running.

## Works, and does not (yet)

- Works (automated evidence): everything above in Chromium with mock IPC; the parsers on this machine's real session files.
- Not confirmed by hand in the packaged app: see the checklist in `DESIGNER-DESK.md`, plus Cmd+click hit-testing, Restore split, the native menus and the Finder action.
- Whether resuming costs tokens before you type was not measured; the app no longer claims it. No cost figures anywhere.
- Shelf items are kept per workspace in the app's browser storage.
- Phone/Tailscale view, session tree and automations are future work.

## Install

Download the DMG from the release page, open it and drag Beads Station to Applications. The app is ad-hoc signed, not notarized: on first launch use right-click → Open. Check the download against the SHA-256 below (`shasum -a 256 <file>`).
