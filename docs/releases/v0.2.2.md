# Beads Station v0.2.2 (prerelease)

Epic `Code-7xc`. Hands-on checklist: [`docs/roadmap-0.2/prompts/HANDS-ON-0.2.2.md`](../roadmap-0.2/prompts/HANDS-ON-0.2.2.md).

## What is new

- **Live usage.** A chip on each agent pane and limits in the status bar for Claude, Codex and Gemini, read from each CLI's own data (a status-line wrapper for Claude). For a hand-typed `claude`, press Add again in Settings → Sessions to enable it. Unknown stays unknown.
- **Offline handoff note.** At 95% of a context window the app writes a handoff note (task, checklist, exact resume command; opens in Pinned) and keeps a prompt journal for agent panes. No model is called.
- **Notification sounds** for waiting, responded and subagent events (Settings → Notifications).
- **Find.** Cmd+F in a pane with every match highlighted, Cmd+Shift+F across the workspace, and highlighted matches in restored panes and History.
- **Bring in a terminal…** adopts a Claude, Codex or Gemini session started outside the app, attaches to a live tmux session, and takes folder drops and proxy-icon drags.
- **Terminal scrolling.** A reader stays put through redraws, tab switches and Gemini output; under mouse tracking only Shift+wheel scrolls the scrollback.
- **Themes.** Eight new themes, Match system appearance, Toggle theme cycling in order or shuffled, theme fixes, and a colour for the command you type (zsh shim, can be turned off).
- **Restored chat panes and History.** A restored chat pane reads as a conversation with Continue and Start new session. History can go to the running session, resume in a new pane, follow live with a New turns pill, and Fork here.
- **Fixes:** the saved screen wraps and clears the scrollbar, dragged paths decode once, `~` replaces home paths in the picker and tooltips, a hint when a folder has no Beads database, a workspace tab overflow menu, dictation no longer scrolls sideways, and Command+V falls back to the native clipboard.

## Works, and does not (yet)

- Works (automated evidence only): all of the above in Chromium with mock IPC; 525 unit tests, 142 live tests and 215 Rust tests pass on the build machine.
- Not confirmed by hand in the packaged app: everything native (real PTY, WKWebView focus, paste and dictation, usage numbers against each CLI's own `/status`, hooks and the status-line wrapper, tmux attach, proxy-icon drags, the zsh shim with a real shell setup, Gemini scrolling).
- Not included: a transcript beside a live pane (unfinished, parked) and the rest of the planned follow-up list. Phone view, session tree and automations are future work.
- Screenshots in `docs/images/releases/v0.2.2/` come from the Chromium test harness with a made-up sample project, not the packaged app.

## Install

Download the DMG from the release page, open it and drag Beads Station to Applications. The app is ad-hoc signed, not notarized: on first launch use right-click then Open. Check the download with `shasum -a 256 <file>`.
