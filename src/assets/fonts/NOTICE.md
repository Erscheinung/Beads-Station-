# Bundled font

`JetBrainsMonoNerdFont-Regular.ttf` is JetBrains Mono patched by the
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) project (the
"JetBrainsMono Nerd Font" family). Terminal panes use it as a fallback so icon
glyphs render inside the app's WebView, which cannot see user-installed fonts.

  Font License 1.1 (full text in `node_modules/@fontsource/jetbrains-mono/LICENSE`
  and at https://openfontlicense.org).
- Nerd Fonts patcher and bundled icon sets: MIT and the per-set licenses listed
  in https://github.com/ryanoasis/nerd-fonts/blob/master/LICENSE.

The file is unmodified from the Nerd Fonts release.
